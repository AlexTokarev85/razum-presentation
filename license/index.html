1.4. Конечный пользователь — физическое лицо, уполномоченное Лицензиатом на использование ЛидГен.

1.5. АРI (Application Programming Interface) – интерфейс прикладного программирования ЛидГен, позволяющий провести интеграцию ЛидГен с информационной системой Лицензиата.

1.6. АPI-лицензия — передаваемые неисключительные права использования ЛидГен в формате API. Состав АPI-лицензии определяется Прайс-листом.

1.7. Ключ разработчика — последовательность символов, буквенно-цифровой код, позволяющий получить доступ к функциональным возможностям ЛидГен, используя программные методы API.

1.8. 4. Порядок предоставления доступа

4.1. В случае не предоставления адреса электронной почты в качестве логина и для отправки кода активации будет использован адрес электронной почты, на который был направлен Лицензиату счет для оплаты.

4.2. Доступ к ЛидГен считается предоставленным Лицензиаром после регистрации учетной записи Лицензиата на сервере ЛидГен. Реализация Лицензиатом доступа осуществляется путем ввода кода активации, полученного от Лицензиара.

4.3. В случае самостоятельного выставления счета и его оплаты Лицензиатом доступ к ЛидГен считается предоставленным Лицензиату после получения Лицензиаром оплаты лицензионного вознаграждения. Реализация Лицензиатом доступа к ЛидГен осуществляется путем самостоятельной регистрации в ЛидГен.

4.4. Для интеграции ЛидГен с информационной системой Лицензиат после оплаты лицензионного вознаграждения, предусмотренного для API-лицензии, в течение 5 (пяти) календарных дней получает от Лицензиара необходимый для интеграции Ключ разработчика.
