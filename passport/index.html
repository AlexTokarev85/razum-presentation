1. ОПИСАНИЕ ПРОДУКТА

1.1. Что такое ЛИДГЕН?

ЛидГен — это интеллектуальная система расширения воронки продаж для компаний-поставщиков, работающих в сфере госзакупок (44‑ФЗ, 223‑ФЗ) и коммерческих тендеров. Система обеспечивает гибкий сбор данных: собственный парсинг всех открытых площадок, а также интеграцию с внешними агрегаторами (Контур.Закупки и др.) и CRM. Это позволяет бесшовно встроить анализ в уже настроенные бизнес-процессы.

1.2. Ключевая ценность

— Экономия времени на анализ тендера.

— Снижение рисков: система выявляет скрытые «подводные камни» в ТЗ и договоре, которые могут привести к убыткам.

— Повышение эффективности: специалист фокусируется на подготовке качественных заявок, а не на чтении сотен страниц документации.

— Персонализация под бизнес клиента: промпты и критерии анализа настраиваются под конкретные товарные группы, требования заказчиков и стратегию участия.

— Полный цикл сопровождения: от аудита текущей деятельности до ежемесячного контроля результатов и корректировки настроек.

1.3. Основные функции

1. Поиск и мониторинг тендеров по 44‑ФЗ, 223‑ФЗ и коммерческим площадкам с гибкими фильтрами (автоматическая настройка фильтров по ОКВЭД/ОКПД2 с помощью ИИ).

2. AI‑анализ по номеру закупки (загрузка документов, извлечение данных, структурирование, распознавание сканов).

3. Пять вкладок анализа:

— Общий анализ — сводка, рекомендация, ключевые риски, прогноз цены, оценка трудозатрат.

— Техническое задание — предмет закупки, конкретные модели, требования к происхождению, сертификации, лицензированию.

— Участие — процедура, сроки, обеспечение, ограничения, предоставление образцов.

— Договор — финансовые условия, гарантии, штрафы, порядок приемки, противоречия.

— Заказчик — история, репутация, постоянные поставщики, платёжная дисциплина.

4. Диалоговое окно с ИИ — возможность задавать любые вопросы по документации тендера (чат по тендеру) с указанием источника ответа.

5. PDF‑отчёты — готовые структурированные документы для печати и согласования.

6. Интеграция с CRM — создание сделки в 1 клик с передачей всех полей и прикреплением PDF‑отчёта (опциональный модуль).

7. Анализ закупок из вашего агрегатора — возможность загружать данные из внешних источников (например, Контур.Закупки) для анализа (опциональный модуль).

8. Публичное API — доступ к REST API для интеграции с вашими системами (опциональный модуль).

9. Пользовательские настройки анализа — добавление собственных критериев (ключевые слова, регулярные выражения) с настройкой цветовой индикации.

3. ТАРИФНЫЕ ПЛАНЫ И МОДУЛИ

3.1. Обязательные этапы для каждого клиента (входят в базовую стоимость)

3.1.1. Аудит тендерной деятельности — анализ портфеля закупок клиента за последние 1–2 года, выявление причин проигрышей, профиль «идеального тендера».

3.1.2. Настройка мониторинга — подключение к необходимым площадкам, настройка фильтров (ОКПД2, регионы, заказчики) с помощью ИИ.

3.1.3. Разработка кастомизированного промпта — адаптация нейросетевых алгоритмов под товарную номенклатуру, внутренние критерии оценки рисков и требований к участнику.

3.1.4. Интеграция с CRM (Bitrix24 / amoCRM) — настройка автоматической передачи тендеров и результатов анализа.

3.1.5. Обучение персонала — групповой или индивидуальный вебинар с демонстрацией работы системы и интерпретацией результатов.

3.1.6. Ежемесячный контроль — анализ статистики использования, корректировка промптов и фильтров, отчёт по эффективности.

3.2. Опциональные модули (доплачиваются отдельно)

— Расширение числа анализов в день (свыше 100).

— Подключение диалогового окна с ИИ по тендеру (чат с источниками).

— Анализ заказчика (репутационный индекс, платёжная дисциплина).

— Импорт данных из внешних агрегаторов (например, Контур.Закупки) через API.

— Публичное REST API для интеграции с внутренними системами клиента.
